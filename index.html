Import direct depuis ton serveur Nitrado sans FTP, sans installation
Pour créer le token : connecte-toi sur nitrado.net, puis ouvre server.nitrado.net/en-US/developer/tokens (ou : ton pseudo en haut à droite → My Account → Developer Portal → Long-life tokens). Donne un nom au token, coche service (+ toute case « gameserver / files » si proposée), clique Create, puis copie le long code affiché. Le token reste dans ton navigateur et ne parle qu'à api.nitrado.net.
Important : les pals rangés dans le coffre à pals de guilde (stockage global) ne sont pas détectables dans la sauvegarde pour l'instant. Avant d'importer, place les pals qui comptent dans ta boîte à pals personnelle (ou ton équipe / une base).

Builds meta par rôle

Les combinaisons de 4 passifs à viser selon le rôle du pal (un pal en porte 4 maximum). Effets vérifiés sur les données du jeu · méta Palworld 1.0. Clique un passif pour le retrouver dans la liste complète, ou un pal conseillé pour ouvrir sa fiche.
Pour obtenir ces passifs : capture de pals sauvages, Yakumo (copie les passifs éligibles), élevage ciblé (garde des parents « propres », 2+2 ou 3+1), Gâteau spécial pour l'héritage multiple, œufs sinistres de l'Arbre-Monde pour les passifs ★5, œufs mutés (Immortel, Anomalie, Baby-sitter, Blindage, Marche Céleste) et la table de chirurgie avec les implants jetables.
