Pensé pour une guilde

Importe le Level.sav de ton serveur (ou branche l'API Nitrado), choisis les membres de ta guilde et Pal-Lab calcule ce que vous pouvez élever ensemble — avec le plan étape par étape.

Je veux ce pal — toutes les façons de l'obtenir

Choisis le pal que tu veux obtenir : je te montre toutes les paires de parents qui le donnent, ce que tu peux faire dès maintenant avec ta collection, et le chemin le plus court depuis tes pals.

Croiser 2 pals

Choisis deux parents pour voir leur enfant. Réutilise l'enfant pour enchaîner les générations.

Chemin le plus court

Nombre minimal de croisements pour passer d'un pal à un autre. L'enfant de chaque étape devient parent de la suivante.

Mes Pals

Coche les pals que tu possèdes (sauvegardé automatiquement dans ton navigateur). Je calcule tout ce que tu peux obtenir en les croisant, génération par génération — clique sur un résultat pour voir le plan d'élevage exact.
📂 Importer — dépose Level.sav, LocalData.sav ou un export guilde-palworld.json ici, ou clique
Solo Steam : %LOCALAPPDATA%\\Pal\\Saved\\SaveGames\\<ID>\\<monde>\\Level.sav · Serveur dédié : récupère Pal/Saved/SaveGames/0/<monde>/Level.sav sur le serveur (FTP/panel) — le LocalData.sav local ne contient que ton équipe de 5.
Analyse 100 % locale, rien n'est envoyé.
🌐 Import direct depuis ton serveur Nitrado — sans FTP, sans installation
Pour créer le token : connecte-toi sur nitrado.net, puis ouvre server.nitrado.net/en-US/developer/tokens (ou : ton pseudo en haut à droite → My Account → Developer Portal → Long-life tokens). Donne un nom au token, coche service (+ toute case « gameserver / files » si proposée), clique Create, puis copie le long code affiché. Le token reste dans ton navigateur et ne parle qu'à api.nitrado.net.
⚠️ Important : les pals rangés dans le coffre à pals de guilde (stockage global) ne sont pas détectables dans la sauvegarde pour l'instant. Avant d'importer, place les pals qui comptent dans ta boîte à pals personnelle (ou ton équipe / une base).

Meta — les builds de passifs qui comptent

Les combinaisons de 4 passifs à viser selon le rôle du pal (un pal en porte 4 maximum). Effets vérifiés sur les données du jeu · méta Palworld 1.0. Clique un passif pour le retrouver dans la liste complète, ou un pal conseillé pour ouvrir sa fiche.
🧪 Pour obtenir ces passifs : capture de pals sauvages, Yakumo (copie les passifs éligibles), élevage ciblé (garde des parents « propres », 2+2 ou 3+1), Gâteau spécial pour l'héritage multiple, œufs sinistres de l'Arbre-Monde pour les passifs ★5, œufs mutés (Immortel, Anomalie, Baby-sitter, Blindage, Marche Céleste) et la table de chirurgie avec les implants jetables.
